communication chapter of the Delta VFD-EL manual, and it was also confirmed
on this drive: all 17 group 00 values read this way match the keypad, the
09.xx values match the communication settings that actually worked, and the
group 12 table matches the size of every group.

RAW VALUE = the integer returned by the drive's Modbus register. Some
parameters have decimal places (keypad 2.5 A is stored as 25, 2.06 as 206),
others are plain selection codes (e.g. 02.00 = 4). Do not convert a raw value
to the keypad value without the Delta parameter definition for that parameter.
